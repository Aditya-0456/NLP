# NLP Text Processing Using Python

## Aim
To implement various Natural Language Processing (NLP)
techniques using NLTK, Stanza, spaCy and Scikit-learn.

## Technologies Used
- Python
- NLTK
- Stanza
- spaCy
- Scikit-learn

## NLP Operations Performed

1. Sentence and Word Tokenization
   - NLTK
   - Stanza
   - spaCy

2. Stopword Removal

3. Stemming

4. Lemmatization

5. Comparison of Stemming and Lemmatization

6. POS Tagging

7. Chunking and Named Entity Recognition

8. TF-IDF Calculation

9. CYK / Chart Parsing

10. N-gram Generation
    - Unigram
    - Bigram
    - Trigram

11. Sentiment Analysis

## Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project:

cd NLP-Text-Processing

Install dependencies:

pip install -r requirements.txt

Download spaCy English model:

python -m spacy download en_core_web_sm

## Run the Program

python nlp_text_processing.py
